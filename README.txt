Real vehicle photos in SVG format, one file per model (lower case):

  axia.svg  viva.svg  myvi.svg  iriz.svg  bezza.svg  saga.svg  persona.svg
  alza.svg  exora.svg  ativa.svg  aruz.svg  x50.svg  x70.svg

Only .svg files are used. To add a new photo, convert it with photo-to-svg.html.
Veltrix checks, in order:
  1. an SVG photo uploaded for that vehicle (Fleet > Edit > Vehicle photo)
  2. <model>.svg in this folder
  3. otherwise the drawn SVG car in the vehicle's colour
